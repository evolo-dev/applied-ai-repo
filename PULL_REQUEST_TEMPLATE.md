# Pull Request Template

---

## What problem does this solve?

Describe the business or technical problem this addresses. Be specific about production concerns (latency, reliability, cost).

## What changes were made?

- [ ] Bug fixes
- [ ] Documentation updates  
- [ ] New features
- [ ] Code quality improvements

## Did you test this in production?

- [ ] Locally tested
- [ ] Performance characteristics validated
- [ ] Edge cases considered

> ⚠️ **Evolo Standard:** This code must be deployable to production, not just work in dev.

---

## Checklist (Required)

Before merging:

- [ ] Does this break existing functionality?
- [ ] Is there documentation?
- [ ] Are performance characteristics acceptable?
- [ ] Can a two-engineer team maintain this?

**Remember:** We're a two-engineer company shipping production systems. Complexity without justification gets rejected.
